# Предыдущие материалы проекта

Актуальные материалы находятся в [results](../results/): презентация в
`presentations`, отчёт в `reports`. В этой папке сохранены прежние версии.

- `presentations/original/` — презентации, которые были в исходном проекте.
- `presentations/early_versions/` — две ранние презентации, ранее лежавшие в `outputs`.
- `presentations/` — промежуточные версии презентации о памяти.
- `reports/original/` — исходные `Отчет.docx` и `REPORT.md`.
- `reports/` — прежний PDF и журнал прошлой подборки запросов к LLM.
- `notes/RAG_agent.md` — прежние заметки к выступлению.

Содержимое перенесено без изменений. Названия путей и результаты внутри старых
материалов относятся к соответствующей версии проекта. Они могут отличаться
от структуры и результатов текущего ручного прогона.
