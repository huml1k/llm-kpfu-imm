# RAG-помощник КФУ с памятью

## Запуск

В PowerShell из папки проекта:

```powershell
python chat.py
```

Ключ и модели читаются из `.env`. В ручном чате этот файл имеет приоритет над
старыми переменными PowerShell. Готовый индекс `data/indexes/index_50` содержит 50 фрагментов
первого документа. Достраивать все 188 фрагментов для запуска не нужно.

Вводишь вопрос после `Ты:` и получаешь ответ. Чат использует настоящий OpenRouter.
На один запуск задан предел 10 запросов API, включая поиск, ответы, сводки и
повторы. Одна реплика может потребовать несколько запросов. Другой предел можно
разрешить явно: `python chat.py --max-api-calls 20`.

Проверка настроек и индекса без обращения к модели: `python chat.py --info`.

## Как увидеть запрос к модели

В чате введи `/debug`, затем свой вопрос. Появятся JSON, подготовленный для LLM,
исходный ответ модели и итоговый ответ бота. Ключ в вывод не включается. Повторный
`/debug` скрывает подробности.

Вопросы, ответы и фактические отправки сохраняются в `data/manual_dialogues.jsonl`.
SQLite находится в `data/rag.sqlite3`, если в `.env` не выбран другой путь.

## Как запустить проект

В PowerShell запусти:

```powershell
python chat.py --user-id сам_придумай --session-id сам_придумай  --max-api-calls макс_кол-во_запросов
```

В `data/manual_dialogues.jsonl` сохраняются вопросы, подготовленные отправки,
исходные ответы модели, `usage`, размеры истории и счётчик запросов. Чтобы
показать запрос и исходный ответ непосредственно в консоли, включи `/debug`
перед нужным вопросом. Заново задавать уже выполненные вопросы для журнала
не требуется. При ошибке остановись и проверь причину, чтобы не тратить квоту
повторением всего сценария.

## Команды

| Команда | Действие |
|---|---|
| `/mode on`, `/mode off`, `/mode` | Включить, выключить или переключить память |
| `/session имя` | Другой диалог того же пользователя |
| `/user имя` | Другой пользователь, сессия main |
| `/debug` | Показать или скрыть отправки LLM |
| `/memory` | Спросить модель о подтверждённых фактах |
| `/forget` или `забудь` | Удалить свои диалоги и факты |
| `/expire` | Состарить свои записи на 181 день и выполнить TTL-очистку |
| `/exit` | Выйти |

Команды «да», «нет», сохранение и удаление не вызывают модель. Вопросы о разговоре
и профиле получает LLM. Вопросы о правилах университета используют LLM и RAG-поиск.

## Файлы проекта

```text
RAG_agent_task/
├── chat.py                       # основной запуск
├── README.md                     # инструкция и сценарий упражнений
├── requirements.txt              # зависимости
├── .env                          # ключ и выбранные модели
├── .env.example                  # пример настроек без ключа
├── memory_agent.py, storage.py   # обработка диалога и SQLite
├── context.py, privacy.py        # сводка и проверка фактов
├── client_rag.py, search_core.py # LLM и поиск по документам
├── остальные модули Python       # конфигурация, API и учёт запросов
├── tools/                        # индексация и вспомогательные скрипты
├── docs/                         # исходные документы КФУ
├── prompts/                      # инструкции моделям
├── data/
│   ├── chunks.json               # все 188 текстовых фрагментов
│   ├── rag.sqlite3               # память и история диалогов
│   ├── manual_dialogues.jsonl    # реальные запросы и ответы ручного чата
│   ├── steps.jsonl               # технические события и usage
│   ├── indexes/
│   │   ├── index_50/             # активный индекс из 50 фрагментов
│   │   ├── openai_original/      # исходный индекс из 188 фрагментов
│   │   └── index_nvidia/         # сохранённый прогресс полного индекса
│   └── evaluation/               # результаты оценок и прежних демонстраций
├── eval/                         # код оценки и эталонные наборы вопросов
├── results/
│   ├── presentations/            # актуальная презентация
│   └── reports/                  # актуальный отчёт PDF и Markdown
└── archive/
    ├── presentations/            # предыдущие и исходные презентации
    ├── reports/                  # предыдущие и исходные отчёты
    └── notes/                    # прежние заметки к выступлению
```

Индексы перенесены целиком вместе с метаданными; в `.env` указан
`RAG_INDEX_DIR=data/indexes/index_50`. База и журналы ручного чата сохранили
свои пути. `.venv` содержит установленные зависимости, `.vscode` — настройки
редактора.

## Вспомогательные команды

Диагностика подключения моделей и контрольного поиска с обращением к API:

```powershell
python tools/check_models.py --check-index
```

Пересоздание текстовых фрагментов из `docs/` без запросов к модели:

```powershell
python tools/e2_chunk.py
```

Построение индекса вызывает embedding API:

```powershell
python tools/e3_index_search.py --build-only
```


В `tools/` также сохранены исходные `e1_embeddings.py`, `run_e5.py` и
`build_judge_pptx.py`. Они относятся к прежним упражнениям; для проверки памяти
используй `chat.py`.

Если зависимости ещё не установлены: `python -m pip install -r requirements.txt`.
